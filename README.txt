STRIDE CLUB — ATHLETICS & MARATHON TRAINING WEBSITE

Pages:
- index.html (Home 1)
- home-2.html (Home 2)
- about.html
- services.html
- programs.html
- events.html
- contact.html

How to run:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For best results, use a local static server (for example: VS Code Live Server).

Features:
- Responsive layouts and mobile navigation
- Persistent light/dark theme
- RTL/LTR direction switch
- Shared responsive inner-page hero sizing
- Scroll reveal, marquee, orbit, floating athlete, image-led feature sections and interactive rotation sections
- FAQ accordions and front-end enquiry form feedback
- Reduced-motion preference support

Notes:
- Photography loads from the Unsplash image CDN, so an internet connection is required for the original photographs. A local branded fallback appears if a remote image fails.
- The contact form is a front-end demo and does not send data to a server.
- The product rotation is a slider-driven visual interaction, not a true 3D product viewer.
- Event dates and contact details are sample website content and should be confirmed before launch.

Update notes: Home 2 now has a distinct editorial headline; testimonial contrast was corrected; two additional image-led sections were added to Services, Programs and Events; footer social marks are inline SVG brand icons.
